# 目の休憩タイマー（Dryeye Timer）

ドライアイ防止のためのパソコン使用タイマー。スマホのブラウザで開いて使う静的Webアプリ（GitHub Pages で公開）。

## 動作

1. スタートすると「再開の合図」が短く鳴り、作業時間の計測開始
2. 作業時間（初期値20分）が経つと「休憩の合図」
3. 休憩時間（初期値1分）が経つと「再開の合図」
4. 以降 2〜3 を繰り返す

作業時間・休憩時間・アラームの長さ・音の種類・音量は設定画面で変更でき、端末に保存される。

## 画面を閉じても鳴る仕組み

JavaScript のタイマーはスマホの画面ロック中に止まるため使わない。代わりに、
「作業＋休憩」1サイクル分の音声トラック（8kHz/8bit WAV、合図の位置以外は無音）を
設定に合わせてブラウザ内で生成し、`<audio loop>` で再生し続ける。
OS からは音楽再生として扱われるので、画面オフ・ロック・ホームに戻っても再生が続き、
合図は音声クロックどおりの時刻に鳴る。画面の残り時間表示も `audio.currentTime` から計算している。

制約：ブラウザのタブ／アプリを終了した場合と、他アプリが音声を再生した場合は止まる。
